File reference

All Rust source files with descriptions. Grouped by module.

Root

PathDescription
src/main.rs Binary entry point. Initialises tracing, loads .env, creates the tokio runtime, and launches the eframe window (800 × 600 min size, native WebGL viewport).
src/app.rs MktNoiseApp — eframe::App impl; drives the update loop, tab bar, status bar, and screenshot capture (ViewportCommand::Screenshot → save_screenshot()).
AppState — all shared runtime state: market_data, analysis, kurtosis_window, corr_lookback, fmp_api_key, nn_feature_flags, screenshot_settings, training_status, loaded_model, plot_3d, chart_heights, available_gpus.
AnalysisResults — derived analysis outputs (volatility, correlation, pca, bond_spreads, kurtosis, randomness).
ChartHeights — 12 per-chart height overrides adjustable at runtime.
Plot3DState — draggable 3D plot state (pitch, yaw, sector pair, texture).
Key methods: recompute_analysis(), recompute_correlation(), recompute_kurtosis(), start_data_fetch().
src/config.rs Constants: SECTOR_ETFS (11 SPDRs), BENCHMARK_SYMBOL = "SPY", DEFAULT_LOOKBACK_DAYS = 730, SHORT_VOL_WINDOW = 21, LONG_VOL_WINDOW = 63, NN_LOOKBACK_DAYS = 60, NN_FORWARD_DAYS = 5, NN_HIDDEN_SIZE = 64, NN_LEARNING_RATE = 1e-3, NN_EPOCHS = 1000, NN_BATCH_SIZE = 32.
Functions: fmp_api_key() (reads FMP_API_KEY env var), load_env() (parses .env), save_env_file() (upserts a key in .env on disk).

src/data/

PathDescription
src/data/mod.rs Re-exports the data sub-modules (cache, cboe, fmp, models, yahoo).
src/data/cache.rs JSON file-based caching. load_json<T>() / save_json<T>() helpers used by all data fetchers and the settings persistence layer. Files live in the process working directory.
src/data/cboe.rs Fetches CBOE data over HTTP with a 6-hour file cache.
fetch_put_call_ratio() — downloads totalpc.csv; returns Vec<PutCallRecord> (date, pc_ratio).
fetch_skew_history() — downloads SKEW_History.csv; returns Vec<SkewRecord> (date, skew).
Handles multiple date formats (YYYY-MM-DD, M/D/YYYY, M/D/YY) via parse_date().
src/data/fmp.rs Financial Modeling Prep API client. fetch_treasury_rates() — retrieves 12-tenor yield curve history. fetch_sector_performance() — snapshot sector average % changes. Both use JSON caching via cache.rs.
src/data/models.rs All domain data structs:
OhlcvBar, SectorTimeSeries (with log_returns(), close_prices(), dates(), highs(), lows()), TreasuryRate (12 tenors, parsed_date()), PutCallRecord, SkewRecord, BondSpread (spread_10y_2y, curve_slope), SectorPerformance, VolatilityMetrics (short_window_vol, long_window_vol, parkinson_vol, vol_ratio), KurtosisAccelMetrics (velocity, acceleration, projected_accel, projected_kurtosis, trend), KurtosisMetrics (symbol, mean, std_dev, excess_kurtosis, skewness, jarque_bera, rolling_*, empirical_density, normal_density, accel_metrics), NnPredictions (vol, randomness, kurtosis per sector), CorrelationMatrix, PcaResult (eigenvalues, eigenvectors, mp_upper), TrainingStatus (Idle/Training/Paused/Complete/Error), GpuAdapterInfo, ComputeStats (CPU%, memory, GPU VRAM/util/temp, samples/s), NnFeatureFlags (sector_volatility, market_randomness, kurtosis), ScreenshotFileType (Png/Jpeg/Tiff), ScreenshotCompression (None/Low/High), ScreenshotSettings (save_path, file_type, compression), MarketData (sectors, benchmark, treasury_rates, sector_performance, put_call_ratio, skew_history, last_refresh).
src/data/yahoo.rs Yahoo Finance OHLCV fetching. fetch_all_sectors() — concurrent fetch of all 11 sector ETFs over DEFAULT_LOOKBACK_DAYS (730 days). fetch_symbol_history() — single symbol. Returns SectorTimeSeries. Uses yahoo_finance_api v4.

src/analysis/

PathDescription
src/analysis/mod.rs Re-exports the analysis sub-modules.
src/analysis/volatility.rs compute_sector_volatility() — rolling short (21-bar) and long (63-bar) annualised log-return vol, Parkinson high-low estimator, and vol ratio (short/long). Returns VolatilityMetrics.
src/analysis/cross_sector.rs compute_correlation_matrix() — full-history Pearson correlation for N sectors.
compute_correlation_matrix_windowed() — windowed version using the last corr_lookback observations.
average_cross_correlation() — mean of off-diagonal elements.
compute_pca() — Jacobi iterative eigendecomposition; returns PcaResult with eigenvalues, eigenvectors, and Marchenko-Pastur upper bound (1 + √(N/T))².
src/analysis/bond_spreads.rs compute_term_spreads() — computes 10Y-2Y term spread and curve slope from TreasuryRate series. Returns Vec<BondSpread>. Inversion is implicitly visible when spread_10y_2y < 0.
src/analysis/kurtosis.rs compute_sector_kurtosis() — rolling excess kurtosis (4th standardised central moment − 3) and rolling skewness over a configurable window; Jarque-Bera normality test; KDE empirical density and fitted normal density curves.
KurtosisAccelMetrics computed when sufficient rolling data exists: velocity (1st differences), acceleration (2nd differences), projected_accel, projected_kurtosis, trend direction.
src/analysis/randomness.rs compute_sector_randomness() — per-sector market randomness / entropy metrics derived from log returns. Returns SectorRandomness used as NN features and displayed in the Dashboard.

src/nn/

PathDescription
src/nn/mod.rs nn module root. Exports LoadedModel type alias (the burn model type used for inference after loading from disk).
src/nn/dataset.rs build_dataset() — constructs time-windowed samples (NN_LOOKBACK_DAYS = 60) from MarketData; features include rolling volatility, log returns, randomness metrics, kurtosis/skewness, cross-correlations, bond spread, yield curve slope, and a VIX proxy (~70 features total). NnFeatureFlags gates feature groups. VolBatcher implements burn's Batcher trait.
src/nn/model.rs VolPredictionModel — single LSTM layer (hidden_size = 64) followed by a Linear projection. Input: feature_size × lookback sequence. Output: per-sector vol + entropy + kurtosis/skewness predictions. Configured via VolPredictionModelConfig.
src/nn/training.rs train() — full training loop: burn Learner, AdamW optimiser (lr = 1e-3), 1000 epochs, batch size 32, MSE loss. Runs on WGPU or ndarray backend based on AppState.use_gpu. Streams TrainingProgress (status, losses, predictions) via Arc<Mutex> channels for live UI updates. run_inference() — forward pass on loaded model.
src/nn/persistence.rs save_model() / load_model() — serialize/deserialize model weights using burn's record API. Saves alongside ModelMetadata (trained_at timestamp, final_loss, feature count). Loaded at AppState::default() to skip retraining.
src/nn/gpu.rs detect_wgpu_adapters() — enumerates WGPU-capable GPU adapters (NVIDIA, AMD, Intel). Returns Vec<GpuAdapterInfo>. Called at startup and after each data refresh.

src/ui/

PathDescription
src/ui/mod.rs Re-exports all ui sub-modules.
src/ui/chart_utils.rs Shared chart helpers. height_control() — drag-to-resize handle drawn below each chart, updates ChartHeights in AppState. HoverSeries — egui_plot series with nearest-point tooltip support.
src/ui/dashboard.rs Dashboard tab. Renders:
— Summary metric cards (sectors loaded, SPY last close, avg cross-correlation, 10Y-2Y spread, treasury data points).
— 3D probability distribution plot (plotters, off-screen render to texture, drag to rotate pitch/yaw, sector X/Y pair selector).
— Sector performance bar chart (FMP data).
— CBOE put/call ratio time series chart.
— CBOE SKEW index time series chart.
src/ui/sector_view.rs Sector Vol tab. Per-sector close price chart, short/long rolling volatility chart, and vol ratio chart. Sector selector dropdown. Resizable chart heights.
src/ui/correlation_view.rs Correlations tab. Lookback selector (30/60/90 days) triggers recompute_correlation(). Renders: N×N correlation matrix heatmap grid, PC loadings heatmap, Marchenko-Pastur noise boundary indicators per principal component.
src/ui/bond_view.rs Bonds tab. Yield curve line plot (multi-tenor snapshot), 10Y-2Y term spread over time, yield curve slope chart. Inversion visually apparent when spread crosses zero.
src/ui/kurtosis_view.rs Kurtosis tab. Sector selector, rolling window selector (triggers recompute_kurtosis()). Charts: empirical KDE vs fitted normal distribution, rolling excess kurtosis, rolling skewness, kurtosis acceleration (velocity + acceleration series from KurtosisAccelMetrics). Displays projected kurtosis and trend direction.
src/ui/nn_view.rs Neural Net tab (heading: "Volatility Regime Prediction"). Model architecture summary. Training controls: Start / Pause / Resume buttons; epoch + loss progress bar; live loss curve chart (resizable). Compute stats panel: backend, CPU%, memory, GPU name/VRAM/utilization/temperature, samples/sec. Predictions table: per-sector vol, randomness, and kurtosis/skewness forecasts. Model save/load buttons + persistence message.
src/ui/settings_view.rs Settings tab. Three sections:
— API Keys: FMP API key text field (show/hide password), Save button writes to .env via config::save_env_file() and clears FMP cache files.
— Screenshot: save path (native OS folder picker via PowerShell FolderBrowserDialog on Windows / zenity on Linux), file type selector (PNG/JPEG/TIFF), compression selector (None/Low/High). Settings persisted to screenshot_settings.json.
— Neural Network Training: feature flag checkboxes (Sector Volatility, Market Randomness, Kurtosis). Settings persisted to nn_feature_flags.json.
