Module overview

app

Application shell, tab routing, state, async orchestration, screenshot capture.

  • MktNoiseApp, Tab (Dashboard/SectorVol/Correlations/Bonds/Kurtosis/NeuralNet/Settings)
  • AppState — market_data, analysis, kurtosis_window, corr_lookback, fmp_api_key
  • AnalysisResults — volatility, correlation, pca, bond_spreads, kurtosis, randomness
  • ChartHeights — per-chart height overrides (12 charts)
  • Plot3DState — pitch/yaw/texture for 3D distribution plot
  • recompute_analysis(), recompute_correlation(), recompute_kurtosis()
  • save_screenshot() — PNG/JPEG/TIFF via image crate

config

Constants, API key loading, and .env file management.

  • SECTOR_ETFS — 11 SPDR sector ETFs (XLK, XLF, XLE…)
  • BENCHMARK_SYMBOL = "SPY", DEFAULT_LOOKBACK_DAYS = 730
  • SHORT_VOL_WINDOW = 21, LONG_VOL_WINDOW = 63
  • NN_LOOKBACK_DAYS = 60, NN_EPOCHS = 1000, NN_HIDDEN_SIZE = 64
  • fmp_api_key(), load_env(), save_env_file()

data

Market data fetching, caching, and domain models.

  • yahoo.rs — OHLCV for 11 sector ETFs + SPY benchmark (2-year lookback)
  • fmp.rs — treasury rates (12 tenors), sector performance via FMP API
  • cboe.rs — put/call ratio (totalpc.csv), CBOE SKEW index history; 6-hour cache
  • cache.rs — JSON file caching (load_json / save_json)
  • models.rs — OhlcvBar, SectorTimeSeries, TreasuryRate, PutCallRecord, SkewRecord, MarketData, VolatilityMetrics, KurtosisMetrics, KurtosisAccelMetrics, BondSpread, CorrelationMatrix, PcaResult, NnPredictions, NnFeatureFlags, ScreenshotSettings, TrainingStatus, ComputeStats, GpuAdapterInfo

analysis

Quantitative analysis algorithms over market data.

  • volatility.rs — short/long rolling vol, Parkinson estimator, vol ratio
  • cross_sector.rs — correlation matrix, Jacobi eigendecomposition, PCA, Marchenko-Pastur upper bound, windowed correlation
  • bond_spreads.rs — 10Y-2Y term spread, yield curve, inversion detection
  • kurtosis.rs — excess kurtosis, skewness, Jarque-Bera, KDE density, rolling kurtosis/skewness, KurtosisAccelMetrics (velocity, acceleration, projection)
  • randomness.rs — per-sector entropy / market randomness metrics

nn

Burn-based LSTM neural network for volatility regime prediction.

  • dataset.rs — build_dataset(), VolBatcher; features: vol, returns, randomness, kurtosis, cross-corr, spread, slope, VIX-proxy (70 features)
  • model.rs — VolPredictionModel (LSTM hidden=64 → Linear), config
  • training.rs — training loop (1000 epochs, batch=32), run_inference()
  • persistence.rs — save/load model weights + ModelMetadata; LoadedModel alias
  • gpu.rs — WGPU adapter detection (NVIDIA/AMD/Intel)

ui

eframe/egui tab views and shared chart utilities.

  • dashboard.rs — summary metric cards, 3D probability distribution plot (plotters, draggable pitch/yaw), sector performance bar chart, put/call ratio + SKEW charts
  • sector_view.rs — price, rolling volatility, vol ratio charts per sector
  • correlation_view.rs — lookback selector (30/60/90d), correlation grid, PCA loadings heatmap, Marchenko-Pastur noise indicators
  • bond_view.rs — yield curve, 10Y-2Y term spread, curve slope
  • kurtosis_view.rs — distribution KDE, rolling kurtosis/skewness, acceleration chart; window selector
  • nn_view.rs — training controls (start/pause/resume), loss curve, compute stats panel, predictions table
  • settings_view.rs — API key editor (show/hide, save to .env), screenshot settings (path/format/compression), NN feature flag toggles
  • chart_utils.rs — height_control(), HoverSeries, shared helpers
